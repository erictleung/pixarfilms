# Themes in Pixar films by Vox

A data set with the themes in Pixar films as described by Vox.

## Usage

``` r
themes_vox
```

## Format

A data frame with 124 rows and 2 columns:

- film:

  name of film

- theme:

  theme in film

## Source

<https://www.vox.com/2015/11/23/9780818/pixar-chart-movies-toy-story-anniversary>
