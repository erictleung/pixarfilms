# Pixar film franchises

A data set with the Pixar films that are part of a franchise and the
name of the franchise.

## Usage

``` r
pixar_franchises
```

## Format

A data frame with 17 rows and 2 columns:

- film:

  name of film

- franchise:

  name of franchise the film is part of

## Details

Note, not all Pixar films are part of a franchise. For example, "A Bug's
Life" is not part of a franchise, but "Toy Story 2" is part of the "Toy
Story" franchise.
